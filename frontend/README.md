# Frontend (Vite + React)

## Pokretanje

1. Instaliraj pakete:

```bash
npm install
```

2. Kopiraj varijable:

```bash
cp .env.example .env
```

3. Pokreni razvojni server:

```bash
npm run dev
```

Aplikacija koristi backend API na `VITE_API_BASE_URL` (zadano `http://localhost:3000/api`).

## Pokriveni moduli

- javno pretraživanje apartmana
- registracija i prijava
- profil korisnika
- rezervacije (gost + vlasnik)
- recenzije i vlasnički odgovor
- poruke unutar rezervacije
- obavijesti
- vlasnička analitika
- admin moderacija apartmana i korisnika
